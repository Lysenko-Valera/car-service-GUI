Информация о приложении:
Это приложение на Python с использованием tkinter, предназначенное для автоматизации работы автосервисов. 
Оно разделено на несколько пакетов и модулей для управления заказами, услугами, механиками и визуализацией данных.
Основной файл main.py запускает приложение и проверяет пароль пользователя, после чего открывается либо окно контроля, либо админ-панель в зависимости от логина и пароля.
Пакет control содержит окно контроля и обработку кнопок. Так же тут имеется управление графиками доходов и успеха механиков через модули profit_diagram и profit_diagram_bd при этом данные берутся из базы month_data.
Пакет admin отвечает за интерфейс админ панели, обработку кнопок и работу с бд db_admin_window,
позволяет создавать заказы через подкаталог create_car с классом Car и дескрипторами для валидации данных.
Бд разделены на активные заказы, сотрудников, услуги, историю выполненных услуг и данные по месяцам.
При создании заказа данные проверяются дескрипторами, сохраняются в бд и отображаются в окне через ScrollText.
Удаление заказа проверяет наличие VIN в истории и добавлять к сделанным услугам новые услуги.


Запуск приложения:
Для запуска склонируйте этот репозиторий и в установить зависимости и запустить файл main.py
